# Розклад ЗТК для Google Sheets (будь-яка група)

Після налаштування все працює саме: ні комп'ютер, ні телефон нічого не запускають.
На телефоні просто відкриваєте таблицю в застосунку Google Таблиці.

```
сайт ЗТК (PDF)  ->  GitHub Actions (кожні 30 хв, Python-парсер)  ->  data/a20.json (усі групи)
                                                                       |
Google Sheets  <-  Apps Script (кожні 30 хв читає a20.json)  <---------+
```

Налаштування робиться один раз, з комп'ютера (~20 хвилин). Далі нічого не чіпаєте.

Групу вибирають у таблиці: аркуш **Налаштування**, клітинка **B4**, випадаючий список. Усі аркуші одразу показують обрану групу.
У файлі `data/a20.json` (назва лишилась старою, щоб не ламати посилання) лежать розклад і заміни всіх груп.

## Крок 1. GitHub

1. Створіть акаунт на github.com (безкоштовно) і новий **публічний** репозиторій, наприклад `ztk-schedule`.
   У файлі лише розклад групи, який і так публічний на сайті коледжу.
2. Завантажте в нього весь вміст цієї папки (Add file, Upload files). Папка `.github` теж має потрапити.
   Якщо перетягування прихованої папки не спрацює, створіть файл `.github/workflows/update.yml` вручну
   (Add file, Create new file, у назві напишіть шлях з похилими рисками) і вставте вміст.
3. Settings, Actions, General, Workflow permissions: виберіть **Read and write permissions**, Save.
4. Вкладка **Actions**: відкрийте «Оновлення даних розкладу», натисніть **Run workflow**.
   Через хвилину має з'явитися зелена позначка. Якщо червона, відкрийте запуск і подивіться крок
   «Зібрати дані з сайту ЗТК»: там написано, що саме не вийшло.
5. Відкрийте `data/a20.json`, натисніть **Raw** і скопіюйте адресу з рядка браузера.
   Вона виглядає так: `https://raw.githubusercontent.com/ВАШ_НІК/ztk-schedule/main/data/a20.json`.

## Крок 2. Google Таблиця

1. Створіть **нову порожню** таблицю (стара з dropdown-ами не потрібна, але скрипт все одно знімає старі правила перевірки).
2. Розширення, **Apps Script**. Видаліть увесь код, вставте вміст `Code.gs`, збережіть.
3. Угорі виберіть функцію **setup** і натисніть «Виконати». Дайте дозволи (Google попередить, що застосунок
   неперевірений: Додатково, Перейти до проєкту).
4. На аркуші **Налаштування** у клітинку **B3** вставте адресу з кроку 1.5.
5. У меню таблиці з'явиться **Розклад, Оновити зараз**. Натисніть, і аркуші заповняться.
   Автооновлення кожні 30 хвилин і щодня о 00:05 вже ввімкнено.

## Як це працює

- **Основний розклад**: скрипт знаходить на сторінці всі посилання «Розклад занять … N курс» і розбирає колонки **всіх груп** за координатами клітинок.
  Якщо PDF якогось курсу не вдалося розібрати, це лише попередження (решта курсів працює). Обмежити курси можна в `config.json`: `"courses": [2, 3]`.
  ЧОТ/НЕ ЧОТ береться з верхньої/нижньої половини клітинки.
- **Заміни**: беруться з посилань за датою на тій самій сторінці. Додатково перевіряється `files/DD.MM.YYYY.pdf` на 7 днів уперед.
  Група порівнюється точно (А20 не плутається з А20А), підтримуються списки груп і римські цифри.
- **ЧОТ/НЕ ЧОТ** визначається за числом місяця: парне число = ЧОТ. 31-ше і 1-ше обидва НЕ ЧОТ.
  У таблиці цих слів не видно: «Поточний розклад» показує Пн-Пт поточного тижня (у суботу й неділю наступного) з уже підібраними парами за датами та замінами (жовте тло).
- Немає пари: «Немає пари», «—», «—». Немає замін: «Немає замін», звичайний розклад показується.
- Службове на аркуші «Налаштування» (посилання, часовий пояс, дзвінки, статус) сховане, видно лише групу.
  Статус з'являється сам, коли є помилка або попередження. Показати все: меню «Розклад, Показати службові налаштування».
- Оформлення: після оновлення скрипта таблиця один раз оформлюється в темно-синьому стилі; далі скрипт змінює лише значення.
  Пункт меню «Розклад, Оформити таблицю» знову перезапише оформлення, тож власні правки кольорів після нього зникнуть.
  Розклад дзвінків редагується на аркуші «Налаштування» (A11:C14).

## Якщо щось не так

| Симптом | Що робити |
|---|---|
| У «Налаштування» B7 «Помилка …» | Перевірте посилання в B3 (воно має відкриватися в браузері) |
| B7 «Дані не оновлювались понад 72 год» | Вкладка Actions: чи не вимкнено запуск за розкладом (GitHub вимикає його після 60 днів без активності) |
| B7 «Помилки збирання …» | Відкрийте запуск в Actions, подивіться текст помилки; ймовірно, ЗТК змінила формат PDF |
| Сайт ЗТК не пускає GitHub | Запустіть `python scripts/build_data.py` на своєму комп'ютері після `pip install -r requirements.txt` і завантажте оновлений `data/a20.json` |

## Для розробників

```
pip install -r requirements.txt
python -m unittest discover -s tests     # парсери на справжніх PDF
node tests/test_code_gs.js               # логіка Code.gs (ЧОТ/НЕ ЧОТ, заміни, вихідні)
python scripts/build_data.py --main-pdf tests/fixtures/schedule_2_course.pdf \
    --changes-pdf tests/fixtures/changes_06.10.2026.pdf --out /tmp/a20.json
```

`group` у `config.json`: група за замовчуванням (її бачить таблиця до першого вибору) і та, що дублюється у верхньому рівні JSON для старих версій скрипта.
`course` у `config.json`: курс, без якого збірка вважається невдалою.
